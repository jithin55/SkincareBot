# 🧴 SkinCareBot – Telegram Chatbot for Skincare Routines

**SkinCareBot** is a friendly Telegram chatbot that provides quick AM/PM skincare routines based on user input like "oily skin with acne" or "dry flaky skin". It uses the **Groq LLM API** to generate concise and chat-style recommendations.

---

## 🚀 Features

- 🧠 Powered by **Groq** LLM (LLaMA 3)
- 💬 Telegram bot interface
- 🌐 Runs on **Flask** with **Webhook** via **ngrok**
- 🤖 Real-time skincare suggestions
- ✨ Chat-style output with emojis

---

## 🛠️ Technologies Used

| Tool | Purpose |
|------|---------|
| **Python** | Core programming language |
| **Flask** | Lightweight web server for handling webhook |
| **Groq API** | AI-powered responses (LLaMA-3 model) |
| **Telegram Bot API** | Send/receive messages |
| **ngrok** | Exposes localhost to public for webhook setup |
