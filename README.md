# SkinCare Routine Telegram Chatbot

This project is a **Telegram chatbot** built using **Flask**, **Groq LLM API**, and **Ngrok**, aimed at helping users build personalized skincare routines based on their skin type and preferences.

---

## 🔧 Technologies Used

- **Flask** – Web framework for Python
- **Telegram Bot API** – Handles user interaction
- **Groq API** – For AI-generated skincare routines (powered by LLM)
- **Ngrok** – Tunnels localhost to the internet for webhook setup

---

## 🧠 Project Overview

Users can chat with the bot on Telegram and receive a customized skincare routine. The bot processes user messages, sends them to the Groq LLM API, and returns helpful skincare steps.

## ⚙️ Setup Instructions

### 1. 🔑 API Keys Required

- **Telegram Bot Token**: Get from [BotFather](https://t.me/botfather)
- **Groq API Key**: Get from [https://console.groq.com](https://console.groq.com)

Store them securely using environment variables or in a `.env` file (do not hardcode).

---

### 2. 🐍 Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. 🚀 Run the Flask Server

```bash
python app.py
```
By default, Flask runs on:

```
http://localhost:5000
```

### 4. 🌍 Expose Localhost with Ngrok

```bash
ngrok http 5000
```
Ngrok will give you a public HTTPS URL like:

```
https://aa6390359814.ngrok-free.app
```

### 5. 🔗 Set Telegram Webhook

Use this format:

```bash
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOUR_NGROK_URL>/webhook
```
Example:

```bash
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://your-ngrok-url/webhook"
```
✅ You should receive a response like:

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

---

## 💬 How It Works

User sends a message to the Telegram bot.

Flask receives the webhook request from Telegram.

Message is sent to Groq LLM API for AI processing.

Groq returns a response with skincare advice.

Flask sends the response back to the user on Telegram.

---

## 📌 Important Notes

Ensure Ngrok and Flask are running before setting the webhook.

Re-run the webhook command if the Ngrok URL changes.

Use .env to store sensitive data and avoid hardcoding tokens.

Free Ngrok accounts reset the domain on every session.
